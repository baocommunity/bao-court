# FIXES — 2026-08-21 V12 audit + architecture deepening of `@bao/court` v0.5.3

Memo for the post-v0.5.2 hardening and refactoring applied to the public
`baocommunity/bao-court` repository (PR #5). Every one of the 35 actionable
findings from the V12 audit is implemented in code; a per-finding status
report lives at `docs/v12-suggested_fixes_v2.md` (untracked, advisory).

## Audit hardening (all 35 actionable V12 findings)

| Area | Fixes |
|---|---|
| Ceremony machines (DKG / vote / signing) | Deep-frozen state on every transition, monotonic timestamps, canonical UTF-8 tie-break, ledger validation barriers (`assertValidRevealLedger`, `assertSigningRecordInvariants`), abort-phase allowlists, roster caps, coercion guards |
| FROST signing | On-curve nonce-point validation at every admission/restore boundary; duplicate/off-roster persisted records fail closed |
| Transport | Outer NIP-59 gift-wrap re-verification before routing; empty-disputeId filter matches nothing; unwrap batch bounds; transient unwrap failures retried (not dropped) |
| Verdicts | Dispute verdict commitments recomputed and enforced at validation/settlement boundaries; evidence hashes canonicalized |
| DKG keygen | Duplicate juror pubkeys rejected; parameter bounds before cryptographic processing |

Three findings ship as documented divergences from V12's patches (abort
allowlists instead of removal, verdict binding at validation boundaries
instead of inside the signing helper, malformed kind filters throw instead of
silently broadening) — rationale in `docs/v12-suggested_fixes_v2.md`.

## Architecture deepening (2026-08-21 review)

Three shared cores extracted (net −87 lines), public API unchanged:

- `courtCeremonyCore.ts` — roster/deadline/phase/blame/caps shared by the
  three ceremony machines (previously duplicated in parallel).
- `courtUnwrapCore.ts` — one filter/dedup/bounds core behind the seckey and
  signer unwrap adapters (the empty-disputeId hardening previously had to be
  applied twice).
- `courtEventParseCore.ts` — tag/content/value primitives shared by the
  lenient (`events.ts`) and strict (`courtProtocolEvents.ts`) parse tiers.

The `appealCoordinator`-as-fourth-machine conversion was evaluated and parked
via `docs/adr/0001`; a domain glossary now lives at `CONTEXT.md`.
