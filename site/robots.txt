# robots.txt — ₿AO Court
#   canonical: https://court.bao.network    mirror: https://bao.network/court/
#
# Two questions, two answers — the same split every BAO host carries:
#
#   1. "May I copy this whole site to train a model?"        -> NO.
#   2. "May I fetch /llms.txt because someone just asked me   -> YES.
#       a question about the ₿AO Court?"
#
# This host serves one landing page plus the discovery documents beside it
# (/llms.txt, /llms.md, /.well-known/llms.txt). The full protocol paper and
# the source of truth live elsewhere and are linked from /llms.txt.
#
# RFC 9309 §2.2.2: the LONGEST matching path wins and `Allow` beats `Disallow`
# at equal length, so each group can end in `Disallow: /` and still hand over
# the paths below. The `$` on each file path is load-bearing: without it a
# robots.txt path is a PREFIX match and `Allow: /llms.txt` would also allow
# /llms.txt.bak.
#
# Non-conformant parsers (Python's `urllib.robotparser` is one: first-match
# prefix, no `$`, no longest-match) read these groups as a plain `Disallow: /`,
# which is what they saw before this file existed.
