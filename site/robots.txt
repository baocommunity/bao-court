# robots.txt — ₿AO Court
#   canonical: https://court.bao.network    mirror: https://bao.network/court/
#
# MAXIMUM DISCOVERY. The point of this host is that an agent — or a person —
# can find out what the ₿AO Court is and where the real material lives. So the
# three discovery documents are readable by EVERY crawler, named or not, and
# only the rest of the site is reserved.
#
# Two questions, two answers:
#
#   1. "May I copy this whole site to train a model?"        -> NO.
#   2. "May I fetch /llms.txt because someone just asked me  -> YES, for any
#       a question about the ₿AO Court?"                        agent, not just
#                                                                the ones we
#                                                                happened to list.
#
# WHY ONE `User-agent: *` GROUP AND NOT A LIST OF NAMES.
# RFC 9309 §2.2.1: when a crawler matches more than one group, the rules are
# COMBINED, and §2.2.2 resolves conflicts by longest path (Allow wins a tie).
# Enumerating agents meant a second party could inject its own group for the
# same agent — which is exactly what happened when the CDN began prepending a
# blanket `Disallow: /` for GPTBot/ClaudeBot, and the carve-out survived only
# because a compliant parser merged the groups. One wildcard group with a
# `Disallow: /` tail and explicit `Allow`s cannot be split that way: a
# prepended group is then the *duplicate*, and the longest-match rule is what
# protects the documents.
#
# PARSER COMPATIBILITY: the discovery paths are deliberately UNANCHORED (no
# `$`). Python's `urllib.robotparser` — and any parser without `$`-anchor
# support — percent-encodes `$` to `%24`, so `Allow: /llms.txt$` never matches
# and the group reads as a plain `Disallow: /`, silently breaking on-demand
# retrieval. A bare path is a prefix match, so `Allow: /llms.txt` also matches
# /llms.txt.bak; that widening is accepted because the origin publishes no such
# neighbour files.
#
# The rights reservation is kept in two forms: the `Disallow` on everything
# except the documents, and the `Content-Signal` line (a Cloudflare-extension
# directive that compliant agents honour and older parsers ignore harmlessly).

# ── Everyone: the discovery documents, and nothing else ──────────────────────
User-agent: *
Content-Signal: search=yes, ai-train=no, use=reference
Allow: /llms.txt
Allow: /llms.md
Allow: /.well-known/llms.txt
Disallow: /

# ── Search engines: the whole site (discovery for humans too) ────────────────
User-agent: Googlebot
Allow: /

User-agent: Bingbot
Allow: /

User-agent: DuckDuckBot
Allow: /

User-agent: Applebot
Allow: /

# they fall under `*` above, which is the carve-out plus a reservation on the
# rest. Adding a named group here would re-create the duplicate-group ambiguity
# this file exists to avoid.
