# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security vulnerabilities.
Report privately to the repository maintainers:

- Open a [private security advisory](https://github.com/baocommunity/bao-court/security/advisories/new)
  (GitHub-native, preferred), or
- Email the maintainers via the repository owner profile.

We aim to respond within 5 business days.

## Scope

Applies to the `@bao/court` protocol code. FROST signing and dispute
logic is security-critical — please include a minimal repro, affected
version, and impact description.
